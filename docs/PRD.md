> 版本:v1.0
> 更新日期:2026-07-14
> 文档负责人:产品组

---

## 1. 文档概述

### 1.1 文档目的
本文档定义 GoodNotes 笔记 App 的产品需求,作为产品设计、开发、测试的依据,确保团队对产品目标、功能范围、用户体验形成一致认知。

### 1.2 产品定位
GoodNotes 是一款**离线优先、云端同步**的跨平台笔记应用,面向需要高效记录、整理、检索信息的个人用户,提供富文本编辑、分类管理、多端同步等核心能力。

### 1.3 目标用户
| 用户画像 | 特征 | 核心诉求 |
|---------|------|---------|
| 学生 | 课堂笔记、复习资料 | 快速记录、手写、图片插入、分类整理 |
| 知识工作者 | 会议纪要、项目文档 | 富文本、搜索、多设备同步、协作 |
| 写作者 | 灵感记录、草稿 | Markdown、版本历史、导出 |
| 生活记录者 | 日记、清单 | 简洁、私密、提醒 |

---

## 2. 产品目标

### 2.1 业务目标
- 6 个月内积累 10 万注册用户,月活 3 万
- 用户次日留存率 ≥ 40%,7 日留存率 ≥ 25%
- 用户日均使用时长 ≥ 5 分钟

### 2.2 体验目标
- 笔记创建到开始编辑 < 1 秒
- 搜索响应 < 200ms
- 离线状态下全功能可用,联网后自动同步

### 2.3 非目标
- 不做团队协作办公套件(非 Notion 替代品)
- 不做知识库/Wiki 系统
- 不做社交媒体功能

## 4. 详细功能说明

### 4.1 笔记管理 (P0)

#### 4.1.1 创建笔记
**用户故事**:作为用户,我希望快速创建一条新笔记,以便记录想法。

**功能描述**:
- 首页悬浮"+"按钮,点击即创建
- 新笔记默认进入编辑器,光标聚焦标题
- 自动保存:每 3 秒或失焦时保存
- 默认归入"未分类"笔记本

**验收标准**:
- ✅ 点击 + 后 < 500ms 进入编辑状态
- ✅ 退出 App 后再进入,内容不丢失
- ✅ 支持空标题保存(显示正文前 20 字)

#### 4.1.2 编辑笔记
**富文本支持范围**:
- 文字格式:加粗、斜体、下划线、删除线
- 段落:标题(H1-H3)、引用、代码块
- 列表:有序、无序、待办清单
- 插入:图片、链接、分割线
- 支持 Markdown 快捷输入

**交互细节**:
- 底部工具栏可滑动展开
- 长按文字弹出格式菜单
- 横屏自动适配宽屏编辑

#### 4.1.3 删除与恢复
- 删除笔记 → 进入"回收站"
- 回收站保留 30 天,过期永久删除
- 支持批量恢复 / 永久删除

#### 4.1.4 置顶与收藏
- 笔记可置顶(列表顶部显示)
- 单笔记本最多置顶 20 条
- 收藏笔记独立列表展示

### 4.2 组织结构 (P0/P1)

#### 4.2.1 笔记本
- 支持多级文件夹(最多 3 层)
- 笔记本可重命名、删除、移动
- 删除笔记本时,内含笔记移至"未分类"

#### 4.2.2 标签系统 (P1)
- 一条笔记可打多个标签
- 标签支持颜色标记
- 标签页展示所有标签云

### 4.3 搜索 (P1)

**搜索范围**:标题 + 正文 + 标签
**搜索能力**:
- 实时搜索(输入即搜)
- 关键词高亮
- 搜索结果按相关度排序
- 支持搜索语法:`tag:工作`、`note:日记`

**验收标准**:
- ✅ 1000 条笔记下搜索 < 200ms
- ✅ 搜索结果精准匹配,无遗漏

### 4.4 云端同步 (P1)

**同步策略**:
- 离线优先:所有操作先写本地
- 增量同步:仅同步变更内容
- 自动同步:网络恢复后 5 秒内触发
- 手动同步:下拉刷新触发

**冲突处理**:
- 同一笔记在多端编辑产生冲突
- 默认策略:以 `updatedAt` 较新为准
- 高级策略:保留两份,用户选择合并

### 4.5 富媒体 (P2)

| 类型 | 支持 | 限制 |
|------|------|------|
| 图片 | JPG/PNG/WEBP | 单张 ≤ 10MB |
| 语音 | 录音 + 转文字 | 单条 ≤ 30 分钟 |
| 附件 | PDF/DOC | 单个 ≤ 50MB |
| 手写 | Canvas 手绘 | -

## 5. 用户流程

### 5.1 核心流程:记录笔记

```
用户打开 App
    ↓
首页(笔记列表)
    ↓ 点击 +
新建笔记 → 进入编辑器
    ↓ 输入内容
自动保存(每3秒/失焦)
    ↓ 点击返回
返回列表(新笔记置顶)
```

### 5.2 同步流程

```
用户编辑笔记
    ↓
写入本地 SQLite
    ↓ UI 立即更新
标记为"待同步"
    ↓
检查网络
    ├─ 有网 → 上传服务器 → 更新同步时间
    └─ 无网 → 等待网络恢复
```

## 6. 非功能需求

### 6.1 性能
| 指标 | 目标值 |
|------|--------|
| 冷启动时间 | ≤ 2 秒 |
| 列表滚动 FPS | ≥ 55 |
| 笔记保存延迟 | ≤ 100ms |
| 搜索响应 | ≤ 200ms |
| 同步延迟 | ≤ 3 秒 |

### 6.2 兼容性
- iOS 13+
- Android 8.0+ (API 26+)
- 屏幕适配:4.7" - 6.9"

### 6.3 安全性
- 传输加密:HTTPS + TLS 1.2+
- 存储加密:本地 SQLite AES-256 加密
- 敏感笔记:应用内锁屏(Biometric)
- 用户数据:不向第三方分享

### 6.4 可用性
- 服务可用性 ≥ 99.5%
- 离线场景 100% 可用
- 数据丢失率 ≤ 0%
